Autenticação

Todas as requisições à API devem incluir uma chave de API no header Authorization: 

Authorization: Bearer YOUR_API_KEY

Rate Limiting

A API implementa rate limiting para proteger o serviço:

  • Padrão: 100 requisições por minuto por API key
  • WhatsApp (Infobip/Twilio): 100 req/min
  • Instagram: 200 req/hora
  • Facebook Messenger: 200 req/hora

Exemplos de Uso

1. Enviar Mensagem de Texto (WhatsApp)

curl -X POST https://your-domain.com/api/messages/text \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+351912345678",
    "text": "Olá! Como posso ajudar?",
    "provider": "infobip"
  }'

2. Validar Número WhatsApp

curl -X GET "https://your-domain.com/api/whatsapp/check-number?phoneNumber=%2B351912345678" \
  -H "Authorization: Bearer YOUR_API_KEY"

3. Enviar HSM Template

curl -X POST https://your-domain.com/api/messages/hsm \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+351912345678",
    "templateId": "template_123",
    "parameters": {
      "name": "João",
      "code": "12345"
    },
    "provider": "infobip"
  }'

4. Enviar Mensagem Instagram

curl -X POST https://your-domain.com/api/messages/text \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "1234567890",
    "text": "Olá do Instagram!",
    "provider": "meta",
    "platform": "instagram"
  }'

5. Consultar Status de Mensagem

curl -X GET https://your-domain.com/api/messages/msg_abc123/status \
  -H "Authorization: Bearer YOUR_API_KEY"

6. Obter Métricas

curl -X GET "https://your-domain.com/metrics/meta?timeRange=24h" \
  -H "Authorization: Bearer YOUR_API_KEY"

Exemplos em JavaScript

// Enviar mensagem de texto
async function sendMessage(phoneNumber, text) {
  const response = await fetch('https://your-domain.com/api/messages/text', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      to: phoneNumber,
      text: text,
      provider: 'infobip'
    })
  });
  
  const data = await response.json();
  console.log('Message ID:', data.data.messageId);
  return data;
}

// Validar número WhatsApp
async function checkWhatsApp(phoneNumber) {
  const response = await fetch(
    `https://your-domain.com/api/whatsapp/check-number?phoneNumber=${encodeURIComponent(phoneNumber)}`,
    {
      headers: {
        'Authorization': 'Bearer YOUR_API_KEY'
      }
    }
  );
  
  const data = await response.json();
  return data.data.hasWhatsApp;
}

Exemplos em PHP

<?php
$client = new GuzzleHttp\Client();

// Enviar mensagem de texto
$response = $client->post('https://your-domain.com/api/messages/text', [
    'headers' => [
        'Authorization' => 'Bearer YOUR_API_KEY',
        'Content-Type' => 'application/json',
    ],
    'json' => [
        'to' => '+351912345678',
        'text' => 'Olá do PHP!',
        'provider' => 'infobip',
    ],
]);

$data = json_decode($response->getBody(), true);
echo "Message ID: " . $data['data']['messageId'];
?>
